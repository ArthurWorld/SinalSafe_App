Pré-requisitos

Node.js em uma versão LTS compatível com o projeto (SDK 57).

Expo Go instalado no celular e compatível com a versão do Expo do projeto.

Computador e celular conectados à mesma rede Wi-Fi.

Como executar

Baixe ou clone o projeto e abra o terminal na pasta do aplicativo, onde está o arquivo package.json.

Instale as dependências:

npm install

Inicie o aplicativo:

npx expo start

Escaneie o QR Code exibido no terminal:

Android: use a opção de escanear QR Code no Expo Go.

iPhone: use a câmera e abra o link no Expo Go.

Mantenha o terminal aberto durante o uso. Para encerrar, pressione Ctrl + C.
