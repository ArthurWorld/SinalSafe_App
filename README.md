# Aplicativo mobile — React Native + Expo

## Pré-requisitos

- [Node.js](https://nodejs.org/) em uma versão LTS compatível com o projeto.
- [Expo Go](https://expo.dev/go) instalado no celular e compatível com a versão do Expo do projeto.
- Computador e celular conectados à mesma rede Wi-Fi.

## Como executar

1. Baixe ou clone o projeto e abra o terminal na pasta do aplicativo, onde está o arquivo `package.json`.

2. Instale as dependências:

   ```bash
   npm install
   ```

3. Inicie o aplicativo:

   ```bash
   npx expo start
   ```

4. Escaneie o QR Code exibido no terminal:
   - **Android:** use a opção de escanear QR Code no Expo Go.
   - **iPhone:** use a câmera e abra o link no Expo Go.

Mantenha o terminal aberto durante o uso. Para encerrar, pressione `Ctrl + C`.

## Caso não conecte

Encerre o servidor e tente iniciar com um túnel:

```bash
npx expo start --tunnel
```

Se o terminal solicitar a instalação de uma dependência para o túnel, confirme.

Referência: [Documentação do Expo](https://docs.expo.dev/get-started/start-developing/).
